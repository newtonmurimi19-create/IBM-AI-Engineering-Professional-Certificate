# Course 13 — Project: Generative AI Applications with RAG and LangChain

**IBM AI Engineering Professional Certificate**

---

## 🚀 Project Overview

This is the final project course of the IBM AI Engineering Professional Certificate.

The project provides practical experience building a real-world Generative AI application using **Retrieval-Augmented Generation (RAG)**, vector databases, LangChain, and a Large Language Model (LLM).

The application combines document retrieval with language model generation to provide users with relevant, context-aware responses.

---

## 🎯 What I Learned

- Gain practical experience building a real-world Generative AI application suitable for showcasing in a professional portfolio.

- Create and configure a **vector database** for storing document embeddings.

- Develop a **retriever** capable of finding relevant document segments based on user queries.

- Configure a **Gradio interface** for user interaction.

- Build a question-answering application using:
  - LangChain
  - Large Language Models (LLMs)
  - Retrieval-Augmented Generation (RAG)

## 🔬 Core Architecture

The project demonstrates the fundamental workflow of a RAG-based Generative AI application:

```text
Documents
    ↓
Document Processing
    ↓
Embeddings
    ↓
Vector Database
    ↓
Retriever
    ↓
Relevant Document Segments
    ↓
Large Language Model
    ↓
Generated Answer
    ↓
Gradio Interface
    ↓
User

🗄️ Vector Database & Retrieval

A vector database is configured to store document embeddings.

When a user submits a query, the retrieval system identifies relevant document segments that can provide context for the language model.

User Query
    ↓
Query Processing
    ↓
Retriever
    ↓
Relevant Documents
    ↓
Context

🤖 Question-Answering Application

The project combines retrieval and generation to create a question-answering application.

User Question
      ↓
Retriever
      ↓
Relevant Context
      ↓
LangChain
      ↓
LLM
      ↓
Generated Response

🖥️ User Interface

The project includes a simple Gradio interface through which users can interact with the application.

The interface provides a practical front end for submitting questions and receiving generated responses.
