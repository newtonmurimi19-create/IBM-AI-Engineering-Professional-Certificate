## 📚 Course Overview

This course focuses on foundational models and techniques for Natural Language Processing (NLP) and language understanding.

It covers methods for transforming text into numerical representations, learning contextual word embeddings, developing neural language models, and building sequence-to-sequence architectures for language tasks.

---

- Explain how the following techniques transform text into numerical features for NLP models:
  - One-hot encoding
  - Bag-of-words
  - Embeddings
  - Embedding bags

- Implement Word2Vec models using:
  - Continuous Bag-of-Words (CBOW)
  - Skip-gram

- Develop and train neural network-based language models using:
  - Statistical N-Grams
  - Feedforward neural network architectures

- Build sequence-to-sequence models using encoder-decoder RNN architectures for tasks including:
  - Machine translation
  - Sequence transformation

## 🔬 Core Concepts

### Text Representation

The course explores several approaches for converting natural language into numerical representations that machine learning models can process:

- One-hot encoding
- Bag-of-words
- Word embeddings
- Embedding bags

### Word Embeddings

Word2Vec techniques are explored through two major architectures:

- Continuous Bag-of-Words (CBOW)
- Skip-gram

### Language Modeling

The course covers neural language modeling approaches based on:

- Statistical N-Grams
- Feedforward neural networks

### Sequence-to-Sequence Modeling

Encoder-decoder RNN architectures are used for sequence transformation tasks, including machine translation.
