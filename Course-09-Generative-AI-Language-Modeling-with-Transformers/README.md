## 🔬 Core Concepts

### Attention Mechanisms

Attention allows Transformer models to capture contextual relationships between tokens in a sequence.

### Transformer Architectures

The course examines different approaches to Transformer-based language modeling, including:

- **Decoder-based architectures** — represented by GPT
- **Encoder-based architectures** — represented by BERT

### Positional Encoding

Positional encoding provides information about token positions within sequences, allowing Transformer architectures to account for sequence order.

### Masking

Masking controls which tokens can be attended to during Transformer processing and is particularly important for sequential language generation.
