# Course 11 — Generative AI Advanced Fine-Tuning for LLMs

**IBM AI Engineering Professional Certificate**

---

## 📚 Course Overview

This course develops advanced Generative AI engineering skills focused on fine-tuning Large Language Models (LLMs).

The course introduces instruction tuning, reward modeling, Reinforcement Learning from Human Feedback (RLHF), Direct Preference Optimization (DPO), and Proximal Policy Optimization (PPO).

---

## 🎯 What I Learned

- Develop advanced Generative AI engineering skills for fine-tuning LLMs.

- Explore **instruction tuning** and **reward modeling** using Hugging Face.

- Understand LLMs as policies and apply concepts related to:
  - Reinforcement Learning from Human Feedback (RLHF)

- Apply **Direct Preference Optimization (DPO)**, including:
  - Partition functions
  - Hugging Face implementations
  - Defining optimal solutions to DPO problems

- Apply **Proximal Policy Optimization (PPO)** using Hugging Face to:
  - Build scoring functions
  - Tokenize datasets
  - Support LLM fine-tuning workflows

## 🔬 Core Concepts

### Instruction Tuning

Instruction tuning adapts language models to better follow task-oriented instructions.

### Reward Modeling

Reward modeling provides a mechanism for evaluating model outputs and supporting reinforcement-learning-based optimization.

### RLHF

The course introduces concepts behind **Reinforcement Learning from Human Feedback (RLHF)** and the treatment of LLMs as policies.

### Direct Preference Optimization

**DPO** provides a preference-based approach for optimizing language models.

The course covers:

- Preference optimization
- Partition functions
- Optimal solutions to DPO problems
- Hugging Face implementations

### Proximal Policy Optimization

**PPO** is explored as a reinforcement learning method for LLM optimization.

The course covers:

- PPO
- Scoring functions
- Dataset tokenization
- Fine-tuning workflows
