# Course 7 — Generative AI and LLMs: Architecture and Data Preparation

**IBM AI Engineering Professional Certificate**

---

## 📚 Course Overview

This course introduces key concepts behind Generative AI and Large Language Models (LLMs), with a focus on generative model architectures, natural language processing, text preprocessing, and NLP data pipelines.

The course covers architectures including RNNs, Transformers, Variational Autoencoders (VAEs), Generative Adversarial Networks (GANs), and diffusion models.

---

## 🎯 What I Learned

- Differentiate between generative AI architectures and models, including:
  - Recurrent Neural Networks (RNNs)
  - Transformers
  - Variational Autoencoders (VAEs)
  - Generative Adversarial Networks (GANs)
  - Diffusion models

- Describe how LLMs such as:
  - GPT
  - BERT
  - BART
  - T5

  are applied to natural language processing tasks.

- Implement tokenization to preprocess raw text using NLP libraries and tokenizers including:
  - NLTK
  - spaCy
  - BertTokenizer
  - XLNetTokenizer

- Create an NLP data loader in PyTorch that handles:
  - Tokenization
  - Numericalization
  - Padding
  - Text dataset preparation
