# IBM AI Engineering Professional Certificate — Portfolio

Welcome to my **IBM AI Engineering Professional Certificate** portfolio.

This repository documents my progression through a comprehensive 13-course AI engineering learning pathway, covering classical machine learning, deep learning, neural networks, computer vision, PyTorch, Keras, TensorFlow, generative AI, natural language processing, transformers, fine-tuning, retrieval-augmented generation (RAG), and AI agents.

The repository combines course documentation with hands-on Jupyter Notebook projects and capstone work completed throughout the program.
